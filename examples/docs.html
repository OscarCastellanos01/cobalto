Webhooks

Recibe un aviso en tu servidor cada vez que cambia el estado de una factura, sin tener que consultar la API.

Disponible desde la API v2

Si usas la v1, sigue la guía de migración.

Configurar un endpoint

Registra la URL que recibirá los eventos desde el panel o con la API. La URL debe usar https y responder con un código 2xx en menos de 5 segundos.

  1. 1Crea el endpointPanel → Configuración → Webhooks.
  2. 2Verifica la firmaCada petición incluye la cabecera Norte-Signature.
  3. 3Responde rápidoProcesa el evento en segundo plano.
routes/web.php
Route::post('/webhooks/norte', function (Request $request) {
    // valida la firma antes de confiar en el contenido
    $firma = hash_hmac('sha256', $request->getContent(), config('services.norte.secret'));
    abort_unless(hash_equals($firma, $request->header('Norte-Signature')), 401);

    ProcesarEvento::dispatch($request->json()->all());
    return response()->noContent();
});

Eventos

Cada petición trae un campo type con uno de estos valores:

EventoCuándo se envía
invoice.paidLa factura se pagó por completo.
invoice.overduePasó la fecha de vencimiento sin pago.
invoice.voidedLa factura se anuló.

Reintentos

Si tu servidor no responde con 2xx, reintentamos hasta 8 veces durante 24 horas, con esperas cada vez más largas.
