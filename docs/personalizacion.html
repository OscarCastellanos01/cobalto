Personalización

Todos los colores pasan por variables CSS. Cambia una y se recolorea toda la librería, sin tocar los componentes.

Personalizador en vivo

Elige un color y mira cómo cambia esta página. El CSS de abajo está listo para pegar en tu proyecto. Los colores se ajustan solos para mantener contraste AA en ambos modos.

Acepta cualquier color en hexadecimal.

Tres niveles

1. Una variable. Cambia `--cb-accent` y se recalculan la escala 50–950, el relleno de botones, los fondos suaves y el foco.

CSS
:root {
  --cb-accent: #e11d48;
}

2. Un tema predefinido. Seis temas, cada uno con su versión clara y oscura.

HTML
<html data-cb-accent="esmeralda">

3. Un tema propio. Define los valores de cada modo con los prefijos `--cb-dark-*` y `--cb-light-*`. Mira el ejemplo completo en Crear un tema propio.

Temas predefinidos

Haz clic para aplicarlo a esta página. La elección se guarda en `localStorage`. Los puntos de color usan `data-cb-accent` anidado: un tema también se puede aplicar solo a una parte de la página.

HTML
<!-- en toda la pagina -->
<html data-cb-accent="violeta">

<!-- solo en una seccion -->
<section data-cb-accent="ambar">...</section>

Claro y oscuro

Sin atributo, Cobalto sigue `prefers-color-scheme` (oscuro si el sistema no indica nada). `data-cb-theme` lo fija, en `html` o en cualquier sección.

HTML
<html data-cb-theme="light">

<!-- una seccion oscura dentro de una pagina clara -->
<section data-cb-theme="dark">...</section>

Las variantes `dark:` y `light:` de Tailwind siguen las mismas reglas:

HTML
<div class="bg-cb-bg-2 dark:bg-cb-bg-3 light:shadow-cb-sm">...</div>

Desde JS:

JS
cobalto.theme.set('light'); // 'dark', 'light' o 'system'
cobalto.theme.toggle();
cobalto.theme.setAccent('rubi');

document.addEventListener('cb:theme', (event) => console.log(event.detail.resolved));

Tokens de color

Cada token existe como variable `--cb-*` y como utilidad de Tailwind: `bg-cb-bg-2`, `text-cb-muted`, `border-cb-line`, `bg-cb-accent/20`...

--cb-bg
Fondo de la página
--cb-bg-2
Superficie elevada (cards en hover, paneles)
--cb-bg-3
Superficie más elevada (hover de menús, kbd)
--cb-line
Bordes y divisiones
--cb-line-2
Bordes de controles
--cb-text
Texto principal
--cb-muted
Texto secundario
--cb-dim
Texto atenuado (metadatos)
--cb-accent
Color de marca
--cb-accent-ink
Texto sobre relleno de acento
--cb-accent-bg
Relleno de acento (botón primario)
--cb-accent-soft
Fondo suave de acento
--cb-success
Éxito
--cb-warning
Aviso
--cb-danger
Error
--cb-info
Información

Crear un tema propio

Copia este bloque, cambia los valores y actívalo con `data-cb-accent="marca"`. Si omites un token, se usa el de Cobalto. Revisa que el texto tenga al menos 4.5:1 de contraste con el fondo.

tema-marca.css
[data-cb-accent="marca"] {
  --cb-dark-bg: #0c0a09;
  --cb-dark-bg-2: #141210;
  --cb-dark-bg-3: #1c1917;
  --cb-dark-line: #292524;
  --cb-dark-line-2: #3a3431;
  --cb-dark-text: #f5f5f4;
  --cb-dark-muted: #a8a29e;
  --cb-dark-dim: #8a837e;
  --cb-dark-accent: #fb923c;
  --cb-dark-accent-ink: #0c0a09;

  --cb-light-bg: #fafaf9;
  --cb-light-bg-2: #f5f5f4;
  --cb-light-bg-3: #e7e5e4;
  --cb-light-line: #d6d3d1;
  --cb-light-line-2: #c4bfbb;
  --cb-light-text: #1c1917;
  --cb-light-muted: #57534e;
  --cb-light-dim: #6b645f;
  --cb-light-accent: #c2410c;
  --cb-light-accent-ink: #ffffff;
}

Los colores de estado también se pueden cambiar por modo: `--cb-dark-success`, `--cb-light-danger`, etc.
