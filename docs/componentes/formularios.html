Formularios

Input, textarea, select, checkbox, radio, switch y archivo, con texto de ayuda y estados de error y éxito.

Error y éxito

El estado de error se activa con aria-invalid="true" en el input o con cb-field--error. El mensaje solo se muestra en estado de error o éxito.

Clases y modificadores

ClaseDescripción
.cb-fieldAgrupa etiqueta, control, ayuda y mensaje.
.cb-field__label, .cb-field__optionalEtiqueta y marca de opcional.
.cb-field__hintTexto de ayuda.
.cb-field__messageMensaje visible solo con error o éxito.
.cb-field--error, .cb-field--successEstados. El error también se activa con aria-invalid="true".
.cb-inputInput, select o textarea. --sm y --lg para tamaños.
.cb-textareaAltura automática y redimensión vertical.
.cb-selectEnvoltorio del select con flecha propia.
.cb-input-group, .cb-input-group__addonInput con prefijo o sufijo.
.cb-check, .cb-check__text, .cb-check__hintEtiqueta clicable para checkbox, radio y switch.
.cb-checkbox, .cb-radio, .cb-switchControles con estilo propio, nativos por debajo.
.cb-fileInput de archivo.
.cb-fieldset, .cb-fieldset__legendGrupo de opciones.

Accesibilidad

  • Cada control necesita un label asociado o aria-label.
  • Relaciona ayuda y errores con aria-describedby.
  • El switch es un checkbox con role="switch": funciona con teclado sin JS.
  • El color no es la única señal de error: el mensaje lo explica en texto.
