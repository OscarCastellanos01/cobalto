Error and success

The error state is enabled with aria-invalid="true" on the input or with cb-field--error. The message only shows in the error or success state.

Classes and modifiers

ClassDescription
.cb-fieldGroups label, control, hint and message.
.cb-field__label, .cb-field__optionalLabel and optional marker.
.cb-field__hintHelp text.
.cb-field__messageMessage visible only on error or success.
.cb-field--error, .cb-field--successStates. The error is also enabled with aria-invalid="true".
.cb-inputInput, select or textarea. --sm and --lg for sizes.
.cb-textareaAuto height and vertical resizing.
.cb-selectWrapper for the select with its own arrow.
.cb-input-group, .cb-input-group__addonInput with prefix or suffix.
.cb-check, .cb-check__text, .cb-check__hintClickable label for checkbox, radio and switch.
.cb-checkbox, .cb-radio, .cb-switchCustom-styled controls, native underneath.
.cb-fileFile input.
.cb-fieldset, .cb-fieldset__legendOption group.

Accessibility

  • Every control needs an associated label or aria-label.
  • Link hints and errors with aria-describedby.
  • The switch is a checkbox with role="switch": it works with the keyboard without JS.
  • Color is not the only error signal: the message explains it in text.
