Classes and modifiers

ClassDescription
.cb-table-wrapBox with a border.
.cb-table-toolbar, .cb-table-toolbar__filtersTop bar with search and filters.
.cb-table-scrollHorizontal scroll on small screens.
.cb-tableTable. --compact reduces the spacing.
.cb-table__strong, .cb-table__num, .cb-table__checkHighlighted cell, numeric cell (right aligned) and selection cell.
.cb-table__sortSort button that JS creates inside the th.
.cb-table-footerFooter with status and pagination.

data-cb-* attributes

AttributeDescription
data-cb-tableEnables the behavior.
data-cb-page-size="n"Rows per page. Without it there is no pagination.
data-cb-sort / data-cb-sort="number|date"On a th, makes that column sortable.
data-valueOn a cell, value used for sorting instead of the text.
data-cb-table-searchInput that searches all columns (ignores accents).
data-cb-table-filter="clave"Select that compares its value with the data-clave of each row.
data-cb-table-select / data-cb-table-select-allRow and header checkboxes.
data-cb-table-status, data-cb-table-paginationWhere to write the status and the pagination.
data-cb-table-emptyText shown when there are no results. Default: "No results".
data-cb-table-status-textStatus template, with {start}, {end} and {total}.
data-cb-table-selected-textSelection template, with {count}.
data-cb-pagination-prev / data-cb-pagination-nextaria-label of the pagination arrows.
data-cb-pagination-pagearia-label of each page, with {page}.

JavaScript

EventWhen it fires
cb:sortOn sort (detail.column, detail.direction).
cb:filterOn search or filter.
cb:pageOn page change (detail.page).
cb:selectOn selection change (detail.rows).

Read the selected rows:

JS
const table = document.querySelector('[data-cb-table]');
table.addEventListener('cb:select', (event) => {
  const ids = event.detail.rows.map((row) => row.dataset.id);
});

Accessibility

  • Sortable headers get aria-sort and a button so they can be used with the keyboard.
  • Selected rows carry aria-selected="true".
  • The status ("Showing 1–5 of 8") lives in an aria-live region.
  • Each row checkbox needs an aria-label with the record's name.
