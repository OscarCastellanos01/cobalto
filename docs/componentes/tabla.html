Clases y modificadores

ClaseDescripción
.cb-table-wrapCaja con borde.
.cb-table-toolbar, .cb-table-toolbar__filtersBarra superior con búsqueda y filtros.
.cb-table-scrollScroll horizontal en pantallas chicas.
.cb-tableTabla. --compact reduce el espaciado.
.cb-table__strong, .cb-table__num, .cb-table__checkCelda destacada, numérica (alineada a la derecha) y de selección.
.cb-table__sortBotón de orden que el JS crea dentro del th.
.cb-table-footerPie con estado y paginación.

Atributos data-cb-*

AtributoDescripción
data-cb-tableActiva el comportamiento.
data-cb-page-size="n"Filas por página. Sin él no hay paginación.
data-cb-sort / data-cb-sort="number|date"En un th, permite ordenar esa columna.
data-valueEn una celda, valor usado para ordenar en lugar del texto.
data-cb-table-searchInput que busca en todas las columnas (ignora tildes).
data-cb-table-filter="clave"Select que compara su valor con data-clave de cada fila.
data-cb-table-select / data-cb-table-select-allCheckboxes de fila y de encabezado.
data-cb-table-status, data-cb-table-paginationDónde escribir el estado y la paginación.
data-cb-table-emptyTexto cuando no hay resultados.

JavaScript

EventoCuándo se dispara
cb:sortAl ordenar (detail.column, detail.direction).
cb:filterAl buscar o filtrar.
cb:pageAl cambiar de página (detail.page).
cb:selectAl cambiar la selección (detail.rows).

Leer las filas seleccionadas:

JS
const table = document.querySelector('[data-cb-table]');
table.addEventListener('cb:select', (event) => {
  const ids = event.detail.rows.map((row) => row.dataset.id);
});

Accesibilidad

  • Los encabezados ordenables reciben aria-sort y un botón para usarlos con teclado.
  • Las filas seleccionadas llevan aria-selected="true".
  • El estado ("Mostrando 1–5 de 8") está en una región aria-live.
  • Cada checkbox de fila necesita aria-label con el nombre del registro.
